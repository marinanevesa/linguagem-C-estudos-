# Estudos em Linguagem C

Este repositório contém exercícios, anotações e pequenos projetos desenvolvidos durante meus estudos da linguagem de programação C.

## Conteúdo

- Sintaxe básica da linguagem C
- Variáveis, constantes e tipos de dados
- Operadores aritméticos e lógicos
- Estruturas de repetição (for, while, do-while)
- Condicionais (if, else, switch)
- Vetores e matrizes
- Funções
- Ponteiros (introdução)
- Manipulação de arquivos (básico)

## Como executar os códigos

Para compilar e executar os programas em C, você pode usar um compilador `gcc`. 

Por exemplo:
```bash
gcc nome-do-arquivo.c -o nome-do-programa
./nome-do-programa
